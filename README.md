# 古本フリマレジ

iPad / Safariで古本フリーマーケットの会計を素早く行う、軽量な静的Webアプリです。売上分析よりも会計操作を優先します。

**初期版を実装しました。iPad Safari実機での検収は未実施です。**

公開先: [古本フリマレジ](https://yama-books.github.io/book-flea-register/)

## 使い方

1. 7種類のマーク（赤/黄/緑/白/青/白丸「そ」/白丸「CD」）はすべて100円で、すぐ使えます。必要なら「設定」で価格と分類名を変更します。
2. 「購入数ぶんタップしてください」のボタン（分類名で表示）を1回タップするごとに1点追加。右の「いまのお会計」に明細・お会計・お預かり・お釣りが出ます。明細の＋/−でも訂正できます。
3. お預かりは「ちょうど」か、合計から自動で出る候補（500円・千円・五千円・一万円単位の切り上げ）をタップ、または入力。お釣りを確認して「完了」。保存成功後に次会計へ移ります。最初からやり直す場合は「やりなおす」。
4. 間違えた会計は履歴から確認付きで取消・訂正できます。記録は削除しません。
5. 営業終了時にCSVとJSONバックアップを保存してください。

金額は最大99,999,999円、単価は1〜1,000,000円、明細の数量は1〜999、会計の合計数量は99,999までです。1明細には同じ色・価格・分類をまとめます。価格は最大30種類です。

## ローカルで動かす

任意の静的HTTPサーバーでこのフォルダを配信し、ブラウザで開きます。例: `python -m http.server 8766 --bind 127.0.0.1`。ファイルを直接開く方法は使わないでください。

自動テストはNode.js 22以降で `npm test`、構文チェックは `npm run check`。依存のインストールは不要です。QR生成・読取・圧縮の3ライブラリはvendor/に同梱しています。`tests/browser.html`のボタンでIndexedDB統合テスト、`tests/layout.html`で横/縦/スマートフォンの配置を確認できます。保存テストは本番とは別DBを使います。

- 色をタップして追加 → 必要なら数量を訂正 → 合計確認 → お預かり入力 → 「完了」で保存して次のお客さんへ。
- 初期価格は100・200・400円の3種類。6種類のマークは初期設定ですべて100円です。
- 添付モデル画像を優先し、シンプルでかわいいUIにします。ネコをSVGで描き直しません。
- 端末内保存。ログイン、クラウドDB、外部API、ISBN読取は初期版に不要です。

## 保存・バックアップ

実装では同じ端末・同じブラウザ・同じサイトの保存領域を使います。ブラウザデータの消去、プライベートブラウズ、端末故障等で消失する可能性があります。営業終了時にCSVと復元用JSONを端末外へ保存してください。CSVだけでは設定・取消関係を完全復元できません。アプリの配信元URLを変更すると別の保存領域になる点にも注意が必要です。

## お客さんへの金額表示

「設定」→「お客さん表示」を開くと接続用QRが自動で準備されます。もう1台でQRを開きます。もう1台に出た返答QRを、レジの「返答QRを読む」で読み取ると接続完了。その後はお会計・お預かり・お釣りがリアルタイム更新され、完了後は「ありがとうございました！」と前回の金額を約10秒表示し、0円の待機表示へ戻ります。次の会計を始めた場合はすぐ新しい金額を表示します。

同じWi-Fiまたはテザリングを推奨。QRは10分間有効、接続後は両画面を開いたままにしてください。回線によって直接接続できない場合があります。詳しくは[接続手順と制限](docs/CUSTOMER_DISPLAY.md)。

ピンクは選択肢から削除し、白丸の「そ」に置き換えました。既存のピンク履歴は保持されます。設定は6種類とも100円へ一度整理し、その後の変更は保持します。

白丸の「CD」マークを追加しました（7種類）。各マークの分類名は設定で変更でき、初期値は赤=文庫、黄=新書、緑=単行本、白=漫画、そ=その他、CD=CD、青=未分類です。分類名はマークのボタンと会計明細に表示し（空欄のマークは色名）、確定時の明細snapshot・内訳・CSVにも使います。設定の「設定をすべて初期状態に戻す」で価格・対応・分類名を初期値に戻せます（売上の記録は消えません）。6マーク版の設定は価格対応を保ったままCDと分類名を追加します（markerVersion:3）。

## メニュー

- **練習モード**: 本番の価格・分類設定で練習。会計エリアは紫色と網掛け、「練習モードです」を表示する。デモの会計・取消・訂正は別DBに残し、本番の売上・採番には入れない。各モードの入力途中の会計も別に保持する。設定の変更は本番モードで行う。
- **全画面**: 対応するブラウザーで開始/終了。切り替えられない場合は案内を表示する。iPad Safariの対応は実機で確認する。
- **山本を呼ぶ**: entrance-counterのGASメール方式を援用。要件を入力して明示送信する。同じブラウザーに入場カウンターの端末設定があれば共通設定を利用できる。練習中は実送信しない。GASのデプロイ/宛先設定/実メール着信は別途必要。詳しくは[メニューと練習](docs/MENU.md)、[呼出設定](docs/CALL_SETUP.md)。

練習中のお客さん画面は待機表示にする。練習CSV/JSONはファイル名に「練習」を付け、練習JSONは本番への復元を拒否する。既存の本番記録は消さない。

## 上部の操作と売上グラフ

「練習モード」「山本を呼ぶ」「設定」は最上部に常時表示します。「お客さん表示」と「全画面」は設定内です。会計中/練習中でも設定からお客さん表示につなげられますが、価格や分類の編集はロックします。全画面はiPadOS 16.4以降のSafariにも用途があり、ブラウザーが対応している時だけボタンを表示します。iPad実機では未検証です。

「きょうの売上」の常時表示の内訳で、分類別の売上金額を円グラフ、金額・点数・構成比を凡例に表示します。色別・価格別の重複した内訳は出しません。表示を「時間帯別」に切り替えると、1時間ごとの売上金額・点数・会計数が見られます。取消済みの会計は除外し、分類は確定時のラベルを使います。時計と日付は端末の現地時間です。

売上欄は合計・内訳・履歴の3領域に整理しました。グラフ内では白マークの漫画を青灰色、その他を紫、CDをオレンジに分けます。円グラフは画面に入ると一度ぐるりと回って表示し、動きを減らす設定では静止表示します。値札や確定履歴の色は変更しません。

メール通知の最新仕様は、固定の共通GAS URL・設定内での合言葉保存・呼出ごとの担当者名必須です。URLの入力は不要です（docs/CALL_SETUP.md）。


2026-10-31更新: 分類別グラフは中央に合計・点数を固定したドーナツ型。項目名と割合を区画内に表示し、入り切らない項目は下の一覧に表示します。画面幅に応じて再配置し、動きを減らす設定にも対応します。接続済みのお客さん画面の通常メッセージは、完了後の「ありがとうございました！」だけです。
