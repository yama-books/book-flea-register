# 古本フリマレジ

iPad / Safariで古本フリーマーケットの会計を素早く行う、軽量な静的Webアプリです。売上分析よりも会計操作を優先します。

**初期版を実装しました。iPad Safari実機での検収は未実施です。**

公開先: [古本フリマレジ](https://yama-books.github.io/book-flea-register/)

## 使い方

1. 7種類のマーク（赤/黄/緑/白/青/白丸「そ」/白丸「CD」）はすべて100円で、すぐ使えます。必要なら「設定」で価格と分類名を変更します。
2. 左のマークを1回タップするごとに1点追加。右の「いまのお会計」に明細・お会計・お預かり・お釣りが出ます。明細の＋/−でも訂正できます。
3. お預かり金額を入力し、お釣りを確認して「完了」。保存成功後に次会計へ移ります。最初からやり直す場合は「やりなおす」。
4. 間違えた会計は履歴から確認付きで取消・訂正できます。記録は削除しません。
5. 営業終了時にCSVとJSONバックアップを保存してください。

金額は最大99,999,999円、単価は1〜1,000,000円、明細の数量は1〜999、会計の合計数量は99,999までです。1明細には同じ色・価格・分類をまとめます。価格は最大30種類です。

## ローカルで動かす

任意の静的HTTPサーバーでこのフォルダを配信し、ブラウザで開きます。例: `python -m http.server 8766 --bind 127.0.0.1`。ファイルを直接開く方法は使わないでください。

自動テストはNode.js 22以降で `npm test`、構文チェックは `npm run check`。依存のインストールは不要です。QR生成・読取・圧縮の3ライブラリはvendor/に同梱しています。`tests/browser.html`のボタンでIndexedDB統合テスト、`tests/layout.html`で横/縦/スマートフォンの配置を確認できます。保存テストは本番とは別DBを使います。

- 色をタップして追加 → 必要なら数量を訂正 → 合計確認 → お預かり入力 → 「完了」で保存して次のお客さんへ。
- 初期価格は100・200・400円の3種類。6種類のマークは初期設定ですべて100円です。
- 添付モデル画像を優先し、シンプルでかわいいUIにします。ネコをSVGで描き直しません。
- 端末内保存。ログイン、クラウドDB、外部API、ISBN読取は初期版に不要です。

## 保存・バックアップ

実装では同じ端末・同じブラウザ・同じサイトの保存領域を使います。ブラウザデータの消去、プライベートブラウズ、端末故障等で消失する可能性があります。営業終了時にCSVと復元用JSONを端末外へ保存してください。CSVだけでは設定・取消関係を完全復元できません。アプリの配信元URLを変更すると別の保存領域になる点にも注意が必要です。

## お客さんへの金額表示

「お客さん表示」を開くと接続用QRが自動で準備されます。もう1台でQRを開きます。もう1台に出た返答QRを、レジの「返答QRを読む」で読み取ると接続完了。その後はお会計・お預かり・お釣りがリアルタイム更新され、完了後は次の会計を始めるまで「ありがとうございました」と前回の金額を表示します。

同じWi-Fiまたはテザリングを推奨。QRは10分間有効、接続後は両画面を開いたままにしてください。回線によって直接接続できない場合があります。詳しくは[接続手順と制限](docs/CUSTOMER_DISPLAY.md)。

ピンクは選択肢から削除し、白丸の「そ」に置き換えました。既存のピンク履歴は保持されます。設定は6種類とも100円へ一度整理し、その後の変更は保持します。

白丸の「CD」マークを追加しました（7種類）。各マークの分類名は設定で変更でき、初期値は赤=文庫、黄=新書、緑=単行本、白=漫画、そ=その他、CD=CD、青=未分類です。分類名はレジ画面に出さず、確定時の明細snapshot・内訳・CSVに使います。6マーク版の設定は価格対応を保ったままCDと分類名を追加します（markerVersion:3）。
