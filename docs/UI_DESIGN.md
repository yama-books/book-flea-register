# UI設計

最新指示: **まずモデル画像から反映。SVGでネコ等を描画しない。必要な操作アイコンだけSVG可。シンプルでかわいく、必要最低限。**

## 画像から継承するもの

白系の背景、濃紺の細い輪郭、平たい大きなボタン、緑の会計領域、青の補助領域、タップで1冊追加できる6色の丸ボタン、小さな読書ネコ。画面全体を1枚の画像として貼らず、文字と入力・ボタンはHTMLで作る。iPad枠・ステータスバー・画像内の文字は部品にしない。

ネコはヘッダーに1匹（表示幅48〜64px）。空状態に置く場合も小さくし、同時に複数の大きなネコや本棚を常設しない。本の並びは任意の小さな装飾。元画像をトレースしたSVGや新規キャラクターは作らない。

## レイアウト

横画面は会計を幅のおよそ2/3、右側を本日概要と折りたたみ履歴にする。縦画面は会計→本日概要→履歴の1列。設定はヘッダーの小さな「設定」ボタンから開く。会計ボタンを操作するために履歴をスクロールする構造にしない。

| 領域 | 内容 |
| --- | --- |
| ヘッダー | 小さな元画像ネコと設定のみ。画面上のアプリ名・英語見出し・副題は表示しない。ブラウザのタブ名は識別用に残す。 |
| 会計上部 | 合計金額を最大表示、冊数（CD含む）を併記 |
| 色選択 | 赤/黄/緑/白/青/白丸の「そ」＋各設定価格。色名と選択枠で判別可能 |
| 数量 | 選択色の価格「100円の本 × 2冊」、大きな−/＋。他明細も短い行で増減可能 |
| 分類 | 「分類を付ける（任意）」を展開して6分類。未分類表示 |
| 支払い | 商品合計、お預かり数字欄、お釣り、不足額、「完了」 |
| 保存後 | 「会計0001・600円を保存しました」、直前取消リンク、空の次会計 |
| 補助 | 本日売上・冊数、履歴、集計、CSV/バックアップ |

価格別の総数と色別内訳は会計内の簡潔な明細で確認できるようにする。同価格の別色は統合表示だけにせず、色別数量も保持する。

## 画像との差分（必ず文章仕様を優先）

- 100/200/300/500円のボタン群 → 初期価格100/200/400円。通常は色に価格を併記し、価格の自由調整は設定へ。
- 「−50円」「＋50円」 → 会計画面から外す。
- 「この本を追加」 → 数量＋へ統合し、1冊ごとの追加操作を増やさない。
- 「この会計を記録」 → 預りと釣りを表示した「完了」。これで履歴へ保存する。
- 大きな空状態イラスト → 小さなネコと簡潔な案内。
- 札という誤字 → 冊（CD混在時は補足）。

## 見た目・操作基準

実装開始用の目安: 背景#FAF9F5、文字#172333、会計アクセント#318B70、補助#4386B5。色ボタンは6色それぞれに名前と価格を表示。白ボタンは濃い枠を付ける。淡色に濃い文字を基本にし、実装時にコントラストを確認する。

日本語本文は標準のゴシック体で16〜18px、合計は36〜48px程度。ドット風は枠と素材に限定する。ピクセルフォントを本文に使わない。画像は縦横比を保持し、拡大し過ぎず、必要ならimage-rendering: pixelatedを使うが元画像が厳密な整数ピクセル絵とは限らない。

主要操作は48px以上、間隔8px以上を目安。hover不要、ピンチ拡大を禁止しない。選択状態・エラー・不足額は色だけに依存しない。ボタンはbutton、入力にはlabelを使い、保存結果は読み上げ可能な通知。ソフトキーボード表示時に預り欄と完了が隠れないことを実機確認する。

SVG操作アイコンは実装時に必要性が出たものだけ。＋/−/設定/履歴/CSVはまず文字ラベルで成立させ、アイコンのみのボタンを増やさない。

## 設定画面

価格行（金額・上下移動・削除）、価格追加、6色の価格選択、範囲/刻み幅生成の折りたたみ欄。適用前にプレビューし、保存でまとめて確定。営業中に設定を誤変更しにくい位置にする。バックアップ・復元・集計は設定または補助領域へまとめ、会計画面を圧迫しない。

## 操作簡略化（2026-10-30追記）

画面上部のタイトルを削除。色ボタンは選択専用ではなく追加操作にする。1回で1冊、同じ色を続けてタップすれば連続追加。金額と冊数は即座に更新する。分類を付ける場合は先に選び、その後の追加明細に適用する。

## 会計集中レイアウト（2026-10-30）

ユーザー指定により、現在の会計と売上を分離した。

| 領域 | 内容 |
| --- | --- |
| 左「マークをタップ」 | 7マーク（4列）を大きく表示。下にお預かり入力と「ちょうど/1,000円/5,000円/10,000円」、大きな「やりなおす」。分類名は出さない |
| 右「いまのお会計」 | 明細（マーク・単価×数量・小計・−/＋）、お会計（最大）、お預かり、お釣り、不足案内、「完了」 |
| 下段「きょうの売上」 | 本日合計・点数・直前取消・内訳・CSV/バックアップと、売上の記録 |

iPad横1024×768では会計部分（上段）が1画面に収まる。縦向き・狭い画面では左→右→売上の順に縦積みする。旧「分類を付ける（任意）」と選択色の数量欄は廃止した。

お客さん画面は「お会計／お預かり／お釣り」の3行を大きく表示する。お会計がない時は「いらっしゃいませ」、会計中は「お会計内容をご確認ください」、完了後は次の会計を始めるまで「ありがとうございました」と前回の金額を表示する。接続状況（問い合わせ用）は、レジは接続ダイアログの見出し、お客さん画面は上部の案内文を3秒以内に5回タップした時だけ表示する。
