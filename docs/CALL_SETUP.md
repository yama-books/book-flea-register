# 「山本を呼ぶ」メール送信設定（古本市レジ）

図書館受付と同一のGASデプロイを利用する。GASウェブアプリのURLはアプリ側へ固定済み。**端末に入力するのは合言葉だけ**。合言葉はGASのスクリプトプロパティ `PASSCODE` と端末内のlocalStorageに保存し、公開GitHubに含めない。送信先はGASの `RECIPIENT` で設定する。

## 別端末のレジ用iPadを設定する

1. [古本市レジ](https://yama-books.github.io/book-flea-register/)をSafariで開く。
2. 「設定」→「メール通知」で合言葉を入力し、「合言葉を保存」。設定はこの端末だけに保存される。
3. 「山本を呼ぶ」から **担当者名（1〜80文字、必須）** と **要件（1〜500文字、必須）** を入力して送信する。**担当者名はメール本文の「担当」に記載する。**
4. 送信失敗時は両方の入力を保持し、自動再送しない。失敗表示が出てもメールが届く場合があるため、再送前に受信を確認する。
5. 練習モードでは「山本を呼ぶ」を操作してもメールは送らない。

同じSafariで図書館受付の合言葉が既に設定されていれば、レジが未設定のときだけ参照する。別iPadは合言葉を個別に一度入力する。旧版の端末設定にあるURLは利用せず、公開コードに組み込んだ共通URLだけを利用する。共通設定JSONの取り込み・書き出しUIは廃止した。

## 件名とGAS更新

共通GASの新コードでは、送信JSONの `source: book-sale` に対して `【古本市レジより】山本を呼ぶ`、`source: library` に対して `【図書館受付より】山本を呼ぶ` を使う。スタッフ名は任意の固定文言ではなくユーザー入力。

GASの稼働コードを変更するには、**既存のGASプロジェクト**の `コード.gs` を最新の [gas/call-staff.gs](../gas/call-staff.gs) に変更し、「デプロイを管理」で**同じデプロイの新バージョン**に更新する。GASのスクリプトプロパティはそのまま。20秒制限・JST 1日50通制限は両アプリ合計。

## 検証

2026-10-30にGAS経由でのメール送信・受信成功がユーザーから報告されたが、当時のメール件名は旧版だった。固定URL版・担当者名の入力必須・新件名での実機送受信は別途検証する。秘密情報や実運用の要件はGitHubへ記録しない。

## 送信中表示と所要時間（2026-10-31）

送信開始から回転マークと文字を表示し、入力/送信/閉じるを無効にする。5秒で「この処理には30秒ほどかかる場合があります」、30秒で通常より遅い旨を表示。応答の確認期限は20秒から60秒へ変更した。これは待機中の案内と確認期限の変更であり、送信速度を改善したという意味ではない。成功/失敗後はタイマーを解除し、失敗時は名前・要件を残す。自動再送はない。

実コードのgas/call-staff.gsには30秒のsleepはない。COOLDOWN_SECONDS=20は送信成功後の連続送信制限で、成功した1通の処理を20秒止める命令ではない。lock.tryLock(5000)は競合時に最大5秒待つ。MailApp.sendEmail、連打制限と送信件数の保存が終わってから成功応答する。したがってブラウザー通信以外にも、GASの起動・サービス呼出・メール送信処理が候補になるが、観測された約30秒の内訳は未計測。

[Google公式のベストプラクティス](https://developers.google.com/apps-script/guides/support/best-practices#minimize_calls_to_other_services)はサービス呼出を減らし、読み書きをまとめる方針を示している。本コードではPropertiesの個別読取りをまとめる改善候補がある。ただし送信件数はロック内で最新値を読む必要があり、ロックや制限を単純に外すべきではない。ライブラリによる起動遅延の一般論も公式にあるが、このGASファイルは追加ライブラリを使っていない。

次に計測するなら、ブラウザーのリクエスト総時間、GAS実行の開始/終了、ロック取得、Properties/Cache、MailAppそれぞれの所要時間を合成データで分けて記録する（合言葉・メール本文・宛先はログに出さない）。GAS実行時間よりブラウザー総時間が長ければ、その差には通信・起動待ち等が含まれる。実行ログだけでその差の原因を断定しない。共有GASの変更・再デプロイ・実メール送信は今回実施していない。送信完了前に成功応答する変更もしていない。
