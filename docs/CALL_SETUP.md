# 山本を呼ぶ：送信設定

entrance-counterのGoogle Apps Script方式を援用した。元フォルダは変更しない。予定表や個人情報は移植しない。ボタン名「山本を呼ぶ」はユーザー指定。

## 既存の送信設定がある場合

同じ端末・同じブラウザー・同じ配信元に入場カウンターの設定（localStorageのentrance-counter-call）があれば、このレジの設定が未保存のときだけ共通設定として使う。設定画面に共通設定使用中と表示する。既存GASへは同じAPI形式で送り、担当欄は「古本フリマレジ」。既存GASのメール件名は元の件名のままとなる。このレジで送信設定を保存した場合はレジ専用設定を優先し、元の設定は変更しない。

## 新しく設定する場合

1. 送信元GoogleアカウントでGoogle Apps Scriptのプロジェクトを用意し、gas/call-staff.gsを貼り付ける。
2. スクリプト プロパティのRECIPIENTに宛先、PASSCODEに合言葉を保存する。ソースやGitHubへ記載しない。
3. 自分として実行するウェブアプリとしてデプロイする。送信元の許可が必要。外部から受付ける構成なので、合言葉を十分長くし、利用者以外へ配らない。
4. レジの「メニュー」→「山本を呼ぶ」→「送信設定」に /macros/s/…/exec のウェブアプリURLと合言葉を入力する。設定はこのブラウザー内だけに保存され、CSV/バックアップへ含めない。
5. 実送信は利用者が本番モードで確認する。練習モードでは設定なしでも操作できるがメールは送らない。

POST / text/plain;charset=utf-8 のJSON: key, text（1〜500文字）, staff, at。成功はHTTP成功かつJSONのok:trueが確認できたときだけ。20秒で応答を確認できなければ入力を残し、自動再送しない。メールが送られて応答だけ失われる場合もあるため、着信を確認してから再操作する。

同梱GASは合言葉確認、20秒の連打制限、1日50通を実施する。日次件数はスクリプト プロパティに保存する。実URL、宛先、合言葉、実際の要件は公開ファイルへ入れない。

## 検証の範囲

ブラウザー/Nodeでは模擬応答・未設定・失敗・入力保持・練習の送信抑止を確認する。GASの実デプロイ、メール着信、iPad Safari実機での送信は未確認。今回、実際の呼出メールを送信していない。
