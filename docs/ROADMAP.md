# 開発計画

初期版では下記1〜4を実装。5のiPad Safari実機検収は未実施。ブラウザと自動テストの実績はdocs/VALIDATION.mdを参照。

1. **会計の最小動線**: 必要に応じたマーク価格設定、6色、数量増減、任意分類、整数の合計/預り/釣り。モデル画像の小さなネコと白基調で作る。
2. **保存の安全性**: IndexedDB、同一会計IDと採番、保存完了後だけリセット、保存失敗・二重タップ・複数タブ競合対策。
3. **履歴と取消**: 本日合計/冊数、会計履歴、確認付き取消、原子的な訂正差替。snapshot不変性。
4. **必要な設定と出力**: 価格追加/削除/並替/範囲刻み、色対応、価格/色/分類別集計、CSV、JSONバックアップ/復元。
5. **公開前の実機会計**: iPad Safari横/縦、数字キーボード、連続会計、保存後再起動、CSVをファイルへ保存、バックアップ復元を確認。

## 最小の受入例

| 操作・条件 | 期待 |
| --- | --- |
| 初期状態 | 価格候補100/200/400円。初期対応は6マークすべて100円 |
| 100円×2＋400円×1、預り1000円 | 3点・600円・釣り400円。完了1回で履歴1件 |
| 上記で預り500円/空欄 | 不足/未入力を表示し完了不可 |
| 同じ単価の赤/青、分類を別々に追加 | 合計を計算でき、色と分類内訳も保持 |
| 0冊、−数量、小数、NaN、上限超過 | 完了不可。数量は0未満にならない |
| 完了を連打、保存中に操作 | 1件のみ記録。保存中はボタン無効 |
| 保存エラー、容量不足、競合 | 成功と表示せず会計入力を残す |
| 再読込/ブラウザ終了後再表示 | 確定済み履歴・設定を再取得 |
| 価格・色対応を変更 | 過去単価・色・分類・金額が不変 |
| 取消/訂正 | 確認あり。元履歴が残り、有効集計のみ更新 |
| 訂正保存の途中失敗 | 元会計取消と差替が片方だけ成立しない |
| 日付境界と取消済み会計 | 現地日付と有効明細で正しい本日集計 |
| CSV | 日本語・引用符・自由入力ラベルが安全。取消区別、明細合計で集計 |
| JSON復元 | 検証/プレビュー/確認付き。失敗時に元データ維持 |

表は受入条件であり、全項目の実機検証完了を意味しない。ユーザーの実装・公開指示に基づき初期版を公開するが、実売上での本番利用前にSafari実機での検収を行う。ISBN・クラウド・在庫・決済はこの計画に追加しない。
