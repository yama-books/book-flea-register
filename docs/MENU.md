# メニューと練習モード

2026-10-30追加。ヘッダーは「お客さん表示」と「メニュー」。メニュー内に練習モード/全画面/山本を呼ぶ/設定をまとめる。

## 練習

本番と同じ操作で追加・お預かり・完了・取消・訂正を練習できる。本番DB `book-flea-register-v1` と練習DB `book-flea-register-practice-v1` を分離する。練習へ入る時・練習状態で再読込する時に本番の設定だけを複写し、練習履歴・取消・採番は維持する。設定変更は本番で行い、練習中は変更/本番バックアップ復元を止める。

未確定会計はモード別のsessionStorageへ保存。切替時に説明付き確認を出し、入力を残して移る。現在のモードはタブごとに保持し、再読込後も練習表示を復元する。確定はどちらも保存成功後だけ次会計に進む。練習のJSONは別formatで、本番のparseBackupに拒否される。CSV/JSONの名前は「練習-」で始める。

会計エリアを紫系の背景・破線・斜めの網掛けにし、濃い文字と白い大きなボタンを維持する。上部に「練習モードです」、記録欄に「本番の売上には含みません」と表示する。完了ボタンも「練習を完了」。ネコは既存のPNGのまま。

練習金額はお客さん画面へ流さず、0円/預りなし/釣りなしの待機表示にする。接続そのものは維持する。山本呼出は練習成功表示だけで、fetchを呼ばず、メールを送らない。

## 全画面

明示タップからFullscreen APIを呼ぶ。開始済みなら終了する。非対応・拒否時はメニューに案内する。[Fullscreen標準](https://fullscreen.spec.whatwg.org/)に従い自動で全画面化しない。iPadでは[Appleの「ホーム画面に追加」](https://support.apple.com/ja-jp/guide/ipad/ipad8f1f7a29/ipados)も利用候補。iPad実機の動作は未検証。

## 呼出

[呼出設定](CALL_SETUP.md)を参照。実際のメール送信は、本番モードで送信ボタンを押した時だけ。失敗・応答未確認なら要件を保持し、自動再送しない。端末設定・要件・宛先をGitへ保存しない。

## 上部常設とグラフへの変更（2026-10-30）

最新ユーザー指示によりメニューへの折りたたみを廃止。最上部は練習モード/山本を呼ぶ/設定の3ボタン。スクロール中もヘッダーを表示する。お客さん表示と全画面は設定内へ移す。会計中と練習中も設定は開けるが、設定の編集と復元は無効にして接続操作だけ可能にする。

全画面は[WebKitのSafari16.4公式説明](https://webkit.org/blog/13966/webkit-features-in-safari-16-4/)でiPadOS対応を確認したため残す。API非対応またはfullscreenEnabled=falseの環境ではボタンを隠す。実機で動作確認したという意味ではない。

内訳は分類別の円グラフ（売上金額）と、切替式の時間帯別棒グラフ（1時間）にする。別色でも同じ分類名なら合算する。未分類は独立、過去ラベルは設定から読み替えない。取消と訂正元を除き、現在有効な会計だけを集計する。端末の現地営業日と現地時刻で表示。売上のない時間帯は最初の会計時刻から最後の会計時刻まで0円で補間し、記録がない場合は空表示にする。グラフに加えて数値の凡例/各時間帯の点数・会計数を表示し、色だけに依存しない。

## 内訳の常時表示とグラフの配色・動き（2026-10-30）

内訳の折りたたみを廃止し、最初から表示する。売上欄は広い画面で左に合計・取消/出力、中央に内訳、右に履歴。幅1000px以下は合計と内訳の2列＋下に履歴、620px以下は縦積み。

白マークはグラフ表示だけ漫画=#8196a8（青灰色）、その他=#9b70b8（紫）、CD=#d68b45（オレンジ）とする。円と凡例は同じ色。分類名が設定で変更されてもマークIDに対応した配色を使う。設定/確定履歴のラベル・色・金額は変更しない。

円グラフは可視領域に25%以上入った時に1秒で1回転して現れる。画面外で先に再生しない。描画差替時は前の監視を終了する。prefers-reduced-motionでは再生せず、監視API非対応時は表示時に開始する。CSSによる描画とアニメーションを使い、新規ライブラリやSVGキャラクターは追加しない。
