- src/calculation.js：closedDays[]（旧データの省略可）、closedDay/finalizeDay。確定日の有効売上・点数・会計数と確定日時を保存。純粋関数で追加・取消・訂正を拒否。確認中に日付が変われば拒否。

### 売上予測と入力制度

- **新規未追跡**src/sales-forecast.js、tests/sales-forecast.test.jsを忘れず公開対象にする。package.json/tests/run-checks.mjsにも追加済み。
- 09:00〜16:30の450分を基準に、当日有効売上÷経過営業時間×450分。1日目は翌日も同ペース、2日目は前日実績＋当日見込み。前日記録がなければ合計は未算出。開始前/最初の1分/記録なしは予測未算出。営業時間後・日次確定後の本日見込みは実績。早めに確定した場合、翌日分は確定までのペースを用いる。
- predictions[]を追記保存：id/staff/amountYen/businessDate/createdAt。負数/小数/上限/空名/改行/日付変更/開催日外を拒否。予測IDの再試行は冪等。予測は売上と別で、日次確定後も入力は可（締切指定はユーザーからない）。

- 予測はJSONに含み、設定同期・日付変更では消さない。予測履歴も復元による削除/書換え/並替えを拒否。
